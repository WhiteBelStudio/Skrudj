# Skrudj — барахолка WhiteBelStudio

Проект объединяет Telegram-бота и VK-бота для подачи, модерации и публикации объявлений, а также безопасных выборочных рассылок.

## Текущий статус

Репозиторий инициализируется. Функциональность ещё не считается реализованной, пока код не добавлен и проверки не пройдены.

## План разработки

1. Зафиксировать архитектуру и правила проекта.
2. Подготовить конфигурацию, зависимости и безопасную загрузку настроек.
3. Спроектировать общую базу данных и миграции.
4. Реализовать Telegram- и VK-интеграции.
5. Создать единый процесс объявлений и модерации.
6. Добавить выборочные рассылки с проверкой согласия пользователей, отписок и ограничений платформ.
7. Добавить тесты, инструкции развёртывания и health-check.

## Безопасность рассылок

- Рассылка отправляется только аудитории, соответствующей выбранным фильтрам и правилам платформы.
- Учитываются согласие на новости, отписки, блокировки и ошибки доставки.
- Перед отправкой предусмотрены предпросмотр, подтверждение и тестовая отправка.
- Токены и пароли не хранятся в репозитории.
